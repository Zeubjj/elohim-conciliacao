# Conciliação Bancária — Grupo Elohim

## Como publicar na Vercel (passo a passo)

### Pré-requisito
Conta criada em github.com e vercel.com com o e-mail eliseufloripa@hotmail.com

---

### PASSO 1 — Criar repositório no GitHub

1. Acesse github.com e faça login
2. Clique no botão verde **"New"** (canto superior esquerdo)
3. Em "Repository name" digite: **elohim-conciliacao**
4. Deixe marcado **"Private"**
5. Clique em **"Create repository"**

---

### PASSO 2 — Fazer upload dos arquivos

Na tela do repositório recém-criado:

1. Clique em **"uploading an existing file"**
2. Arraste **todos os arquivos desta pasta** para a área indicada
   - Atenção: arraste também a pasta **src** com os arquivos dentro
3. Na parte de baixo escreva: `primeiro upload`
4. Clique em **"Commit changes"**

---

### PASSO 3 — Publicar na Vercel

1. Acesse vercel.com e faça login
2. Clique em **"Add New Project"**
3. Clique em **"Import Git Repository"**
4. Conecte sua conta GitHub se solicitado
5. Selecione o repositório **elohim-conciliacao**
6. Clique em **"Deploy"**
7. Aguarde 2 minutos

Pronto. A Vercel vai gerar um link como:
**https://elohim-conciliacao.vercel.app**

---

### PASSO 4 — Compartilhar com a equipe

Copie o link gerado e envie para Marcela, Bruna e os gerentes de loja.
Funciona em qualquer navegador, sem instalar nada.

---

## Como usar o sistema

1. Abrir o link no navegador
2. Selecionar a loja (grid com as 10 lojas já cadastradas)
3. Preencher período e responsável
4. Carregar os 4 arquivos:
   - Extrato Santander (.OFX)
   - Getnet — Vendas (.xlsx)
   - iFood — Pedidos (.xlsx)
   - SWfast — Receitas (.xlsx)
5. Clicar em **Processar Conciliação**
6. Analisar divergências, preencher observações
7. Clicar em **Exportar Excel** para gerar o relatório
